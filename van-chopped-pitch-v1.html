Why this matters: every AI coding tool grows its own dotfolder of skills, agents and rules, plus your own pile of prompts and one-off HTML files. Nothing indexes all of it in one place — until you point this at your drives.
What it does

Not just a file list.
A classifier.

Anyone can glob for *.html. The hard part is knowing which HTML is a real document and which is a Vue partial three folders deep in node_modules.

🔍
The HTML qualifier
A weighted score of path and content signals separates standalone documents from framework-embedded fragments, with the reasons shown, not hidden.
📤
Promote embedded → document
One click copies a locked, read-only embedded HTML file out to your documents folder as an editable standalone doc. The original is never touched.
⚡
Live file watching
Recursive fs.watch, 0.5s debounce, pushed to the UI over SSE — edit a file in your editor and watch the browser catch up.
Zero dependencies
node scripts/seed-demo.js && node server.js — no install step, no lockfile, no supply chain to audit before you run it.
Multi-tool dedup
One physical file symlinked into .claude, .cursor, and .codex collapses to a single record with a badge per tool.
Six stages, one page

Point, scan, edit.
That's the whole thing.

The same pipeline Chops uses for skills, generalized to prompts, HTML, components, skills, agents, and rules.

1
Add your folders
~/Sites, ~/Documents/Prompts, a project directory — it also auto-discovers ~/.claude, ~/.cursor, ~/.codex on its own.
2
It walks and classifies
Recursive scan, symlink resolution, frontmatter and component parsing, the HTML qualifier scoring document vs. embedded — deduped by realpath.
Browse, tag, edit
List or live-thumbnail grid, edit source and frontmatter fields, group into collections — writes land back on disk, not in a database.
